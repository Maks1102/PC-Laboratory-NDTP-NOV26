# Аудио (п.7 TODO)

Игра ищет файлы в этой папке и подхватывает их автоматически. Если файла нет —
звучит процедурный плейсхолдер, генерируемый `scripts/autoload/audio_manager.gd`.

## Ожидаемые файлы

| Файл | Когда звучит | Шина |
|---|---|---|
| `click.wav` (или `.ogg`) | клик по любой кнопке UI | SFX |
| `snap.wav` | деталь встала на место (snap-установка) | SFX |
| `power.wav` | короткое «дзынь» установки / полка после snap | SFX |
| `error.wav` | неверная деталь или слот (тост) | SFX |
| `success.wav` | сборка завершена (assembly_completed) | SFX |
| `ambient.wav` | эмбиент помещения — **играется только при наличии файла** (иначе тишина) | Music |
| `fan.wav` | гул вентиляторов после «Включить компьютер», 3D, зациклен | SFX |

Требования к файлам: исправны, пики не клиппятся, `ambient`/`fan` — с бесшовным циклом.

## Замена плейсхолдеров

Просто положите файлы с этими именами в эту папку и выполните
`godot --headless --path . --import`. Лицензия на файлы — ваша ответственность;
подпишите источник тут, если используете сторонние записи.
